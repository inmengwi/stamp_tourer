## 프로젝트 개요

**Stamp Tourer**는 각종 스탬프 투어를 즐기는 사람들이:

- 다양한 스탬프 투어를 탐색하고
- 투어 계획을 세우고
- 수집한 스탬프를 기록하며
- 다른 투어러들과 경험을 공유하고
- 함께 투어를 즐길 수 있는

소셜 플랫폼 앱입니다.
