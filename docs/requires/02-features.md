# 핵심 기능 명세

## 1. 스탬프 투어 탐색 (Discover)

스탬프 투어를 검색하고 발견하는 기능입니다.

### 1.1 투어 카탈로그

전국의 스탬프 투어 목록을 제공합니다.

**투어 종류 예시:**
- 철도 스탬프 (기차역, 지하철역)
- 등대 투어 스탬프 (등대)
- 관광지 스탬프 (국립공원, 유적지, 박물관, 국가문화유산)
- 축제/이벤트 스탬프 (시즌 한정)
- 지역 스탬프 (시/군/구 단위)
- 테마 스탬프 (카페 투어, 빵집 투어 등)

### 1.2 카테고리 분류

| 분류 기준 | 예시 |
|-----------|------|
| 테마별 | 철도, 관광, 축제, 카페, 맛집 |
| 지역별 | 서울, 부산, 제주 등 |
| 난이도별 | 초급(5개 미만), 중급(5-20개), 고급(20개 이상) |
| 소요시간별 | 반나절, 하루, 주말, 장기 |
| 비용별 | 무료, 저비용, 고비용 |

### 1.3 검색 및 필터

- **키워드 검색**: 투어 이름, 지역, 테마
- **현재 위치 기반**: 내 주변 스탬프/투어
- **기간 필터**: 진행 중, 상시, 예정
- **정렬**: 인기순, 최신순, 거리순, 리뷰순

### 1.4 투어 상세 정보

각 투어에 대해 다음 정보를 제공합니다:

- 투어 이름 및 설명
- 스탬프 개수 및 위치 목록
- 운영 기간 및 시간
- 완주 조건 및 보상/특전
- 사용자 리뷰 및 평점
- 예상 소요 시간 및 비용

---

### 1.5 투어 구조 확장 (subTours)

- **복합 코스 지원**: 하나의 투어 아래 여러 하위 코스(`subTours`)를 구성 가능
- **하위 코스 단위 정보**: 코스 제목, 지역/테마 맥락, 코스별 스탬프 목록
- **스탬프 평탄화 제공**: UI/진행률 계산을 위해 `subTours[].stamps`를 단일 스팟 목록으로 변환 지원
- **중복 거점 처리**: 동일 장소가 여러 하위 코스에 포함될 수 있으며, 운영 정책에 따라 코스별 인정 규칙 안내

## 2. 내 투어 계획 (Plan)

참여할 투어를 선택하고 일정을 계획하는 기능입니다.

### 2.1 투어 참여 관리

- **위시리스트**: 관심 있는 투어 저장
- **참여 선언**: 투어 참여 등록
- **진행 중 투어**: 현재 진행 중인 투어 목록
- **완료 투어**: 완주한 투어 아카이브

### 2.2 일정 플래너

- **날짜 선택**: 투어 예정일 설정
- **경로 최적화**: 스탬프 위치 간 최적 경로 추천
- **예상 소요시간**: 이동 시간 + 체류 시간 계산
- **교통 정보**: 대중교통/자가용 경로 연동
- **지도 연동**: 네이버맵/카카오맵/구글맵

### 2.3 체크리스트

- **스탬프 현황**: 획득/미획득 상태 표시
- **진행률**: 퍼센트 및 프로그레스 바
- **남은 스탬프**: 미획득 스탬프 위치 안내

### 2.4 알림 기능

| 알림 종류 | 설명 |
|-----------|------|
| 마감 임박 | 투어 종료일 D-7, D-3, D-1 알림 |
| 근처 스탬프 | GPS 기반 반경 내 스탬프 알림 |
| 운영시간 | 방문 예정 스탬프 운영시간 알림 |
| 투어 업데이트 | 새 스탬프 추가, 정보 변경 알림 |

---

### 2.5 투어 등록

- **등록 시작**: 투어 이름/설명 입력 후 온라인 정보 조회
- **온라인 조회 기반 초안 생성**: 키워드 매칭 결과를 초기 폼으로 자동 채움
- **편집 가능 항목**: 기본 정보, 스팟, 마일스톤, 주의사항, 문의처, 인증 방식
- **수동 보완**: 조회 결과가 없을 경우 빈 폼으로 직접 작성
- **등록 완료 동작**: 내 투어 목록 반영 후 상세 화면으로 즉시 이동

## 3. 스탬프 기록 (Collect)

획득한 스탬프를 기록하고 관리하는 기능입니다.

### 3.1 스탬프 인증 방식

| 방식 | 설명 | 장단점 |
|------|------|--------|
| QR 코드 스캔 | 현장 QR 코드 스캔 | 정확하나 QR 설치 필요 |
| GPS 체크인 | 위치 기반 자동 인증 | 간편하나 위치 조작 가능 |
| 사진 업로드 | 스탬프 사진 촬영 | 유연하나 검증 어려움 |
| 수동 입력 | 사용자 직접 체크 | 가장 간편하나 신뢰도 낮음 |

### 3.2 컬렉션 앨범

- **스탬프 갤러리**: 획득한 스탬프 이미지 모음
- **투어별 정리**: 투어 단위로 스탬프 그룹화
- **시간순 정렬**: 획득 날짜별 타임라인
- **즐겨찾기**: 특별한 스탬프 마킹

### 3.3 통계 대시보드

- **총 스탬프 수**: 전체 획득 스탬프 개수
- **완주 투어 수**: 완료한 투어 개수
- **방문 지역**: 히트맵으로 시각화
- **활동 캘린더**: 월별 스탬프 활동 현황
- **연속 기록**: 연속 활동일 스트릭

## 4. 소셜 및 커뮤니티 (Connect)

다른 투어러들과 소통하고 공유하는 기능입니다.

### 4.1 프로필

- **기본 정보**: 닉네임, 프로필 사진, 자기소개
- **스탬프 통계**: 총 획득 수, 완주 투어 수
- **뱃지 진열**: 획득한 업적 뱃지 표시
- **활동 히스토리**: 최근 활동 목록

### 4.2 피드

- **팔로잉 피드**: 팔로우한 사람들의 활동
- **추천 피드**: 인기/추천 게시물
- **해시태그**: #철도스탬프 #제주투어 등
- **게시물 유형**: 스탬프 획득, 투어 완주, 후기

### 4.3 팔로우/구독

- **팔로우**: 다른 사용자 팔로우
- **팔로워**: 나를 팔로우한 사용자
- **알림**: 팔로우한 사람의 새 활동 알림

### 4.4 그룹 투어

- **그룹 생성**: 함께 투어할 그룹 만들기
- **멤버 초대**: 친구 초대 (링크/검색)
- **일정 공유**: 그룹원 간 일정 동기화
- **실시간 위치**: 투어 중 멤버 위치 공유 (선택)
- **그룹 채팅**: 멤버 간 소통

### 4.5 리뷰 및 팁

- **투어 리뷰**: 별점 + 텍스트 리뷰
- **스탬프별 팁**: 위치 힌트, 운영시간 정보
- **사진 후기**: 현장 사진 공유
- **Q&A**: 질문/답변 게시판

## 5. 게이미피케이션 (Engage)

사용자 참여를 유도하는 게임 요소입니다.

### 5.1 뱃지/업적

| 뱃지 | 조건 |
|------|------|
| 첫 발걸음 | 첫 스탬프 획득 |
| 열정 투어러 | 10개 스탬프 획득 |
| 완주자 | 첫 투어 완주 |
| 탐험가 | 5개 지역 방문 |
| 전국구 | 전국 17개 시도 방문 |
| 소셜 스타 | 팔로워 100명 달성 |
| 리뷰왕 | 리뷰 50개 작성 |

### 5.2 랭킹

- **주간/월간 랭킹**: 기간별 활동량 순위
- **지역별 랭킹**: 지역 내 순위
- **투어별 랭킹**: 특정 투어 참여자 순위
- **친구 랭킹**: 팔로우한 사람들 중 순위

### 5.3 챌린지

- **주간 챌린지**: 이번 주 미션 (예: 카페 스탬프 3개)
- **월간 챌린지**: 이번 달 미션 (예: 새 지역 방문)
- **시즌 챌린지**: 시즌 한정 특별 미션
- **커뮤니티 챌린지**: 전체 사용자 협동 미션
